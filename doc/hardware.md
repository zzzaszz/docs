# 硬件
## 电压、电流、功率

| 概念 | 含义 | 常用单位 |
|---|---|---|
| 电压 U | 推动电荷流动的电势差 | V |
| 电流 I | 电荷流动的速率 | A / mA |
| 功率 P | 电能消耗或输出的速率 | W |

```text
P = U × I
# 例：5V 供电，电流 0.5A → 功率 2.5W
```

看电源参数只要会三件事：电压对不对、电流够不够、会不会短路。

---

## 3.3V 与 5V：最容易烧板的地方

- ESP32 的 GPIO 是 **3.3V 电平**，绝大多数引脚**不耐 5V**，直接接 5V 信号会损坏芯片。
- 板子上的 5V 一般只用于：USB 输入、部分外设供电（如 ws2812、继电器模块）。
- 模块标 `VCC 3.3V` 就接 3.3V，标 `5V` 才接 5V，不确定时先查模块手册。

安全红线：

1. 不要接市电。
2. 不要把 5V 直接接到 GPIO。
3. 通电状态下不要随意短接引脚、不要插拔杜邦线。
4. 接线前先断电，接完检查一遍再上电。

## GPIO

通用输入输出引脚，可读电平（按钮）也可输出电平（LED）。

- 输出能力有限，单个引脚一般几十 mA，驱动电机、灯带要走外部电源 + 三极管/MOS。
- 部分引脚有复用限制：启动时电平不对会导致进不了系统、下载模式异常。
- ESP32-S3 的 GPIO 编号不连续，Flash / PSRAM 占用的那几个（约 26~32）不要占用。
- 部分引脚只有输入能力或带内部上下拉，接之前查引脚定义表。

## 三种常见通信总线

| 总线 | 线数 | 速度 | 典型用途 |
|---|---|---|---|
| I²C | SDA / SCL 两根 | 100k~400kHz | 传感器、触摸芯片、EEPROM |
| SPI | SCK / MOSI / MISO / CS | 几 MHz ~ 几十 MHz | 屏幕、SD 卡、高速外设 |
| UART | TX / RX（+GND） | 常见 115200 | 串口日志、模块通信 |

要点：

- **I²C 需要上拉电阻**，多数模块自带；同一总线设备地址不能冲突。
- **SPI 靠 CS 选片**，一主多从时每个从设备一根 CS。
- **UART 是交叉接**：A 的 TX 接 B 的 RX，并且必须共地。
- 三种总线都要 **共地（GND）**，只接信号线不接地是最常见的“没反应”原因。

## ESP32-S3 资源速记

- 双核 Xtensa LX7，主频一般 240MHz，带 Wi-Fi + BLE。
- 常见 Flash 8/16MB、PSRAM 2/8MB，跑 LVGL 建议带 PSRAM。
- 外设：多路 GPIO、2 路 I²C、多路 SPI、3 路 UART、ADC、PWM(LEDC)、USB。
- ADC 为 12 位，精度一般，测量电池电压够用，别当万用表用。

## 烧录与运行

```text
电脑 --USB--> 板载 USB 转串口/原生 USB --> ESP32-S3
```

- 常见两种下载方式：板载 USB 转串口芯片（CH340/CP2102 类），或 ESP32-S3 原生 USB。
- 进不了下载模式时：**按住 BOOT 不放，点一下 RST 松开**，再点上传。
- 上传失败先看三件事：驱动装没装、串口号选对没、有没有别的串口工具占着端口。
- 程序跑起来后可以用串口日志看输出，波特率一般 115200。

## 屏幕与 LVGL

### 屏幕基础参数

- **分辨率**：如 320×240、480×320，决定绘图坐标范围。
- **颜色深度**：常见 RGB565（16 位，2 字节/像素），一张 320×240 全屏缓冲约 150KB。
- **驱动 IC**：常见 ST7789、ILI9341 一类，具体型号以板子原理图和例程为准。
- **触摸**：电容屏常见 I²C 接口的触摸芯片（GT911、CST328 一类），坐标需要做方向/镜像校正。

### LVGL 要点

- 开源嵌入式 GUI 库，控件（label、bar、btn、table）都是对象，靠事件回调响应。
- 用 **局部刷新 + 双缓冲**，不要整屏重绘，否则会闪。
- 刷新是单线程的：网络回调里不要直接改控件，交给主循环/任务队列处理。
- 内存吃紧时优先降颜色深度、减少同时存在的控件和图片资源。

## 网络长连接

- **Wi-Fi**：连上不等于能用，要判断是否真正拿到 IP 并通外网。
- **MQTT**：适合设备上报/订阅，需要心跳（keepalive）和断线重连。
- **WebSocket**：适合和 Spring Boot 服务双向推送，同样要做重连和退避。
- 断网重连要写指数退避（1s、2s、4s…），不要死循环猛连，容易把路由器打挂。
- 涉及时间的地方记得做 NTP 对时，否则日志时间线全乱。

## 串口调试与排障

| 现象 | 优先排查 |
|---|---|
| 黑屏 | 背光是否供电、屏幕初始化代码、SPI 引脚定义 |
| 一上电就重启 | 供电电流不足、看门狗复位、程序崩溃后 panic 重启 |
| 连不上 Wi-Fi | SSID/密码、2.4G/5G 频段、天线 |
| 触摸没反应 | I²C 地址、触摸中断脚、坐标校准 |
| 烧录失败 | 驱动、串口占用、BOOT 按键时序、供电 |

万用表三件事就够用：量直流电压、测通断、查短路。

## 入门学习顺序

1. 硬件与供电安全 —— 能安全接线、不烧板。
2. ESP32 与烧录 —— 能跑通官方示例。
3. C/C++ 基础 —— 能看懂并修改示例代码。
4. 屏幕与 LVGL —— 能做出状态卡片、进度条、多页面。
5. 网络与长连接 —— 能接收 PC / NAS 推送并自动重连。
6. 调试与维护 —— 出问题能定位，而不是只会重新烧录。
